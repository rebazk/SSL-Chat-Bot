# Demo Answer Key Template

This worksheet matches the current 11-question Phase 1 demo set. Use it to judge whether retrieval, answers, and citations are aligned with the intended evidence.

## How To Use

- Check the top retrieved chunks before scoring the answer.
- Confirm that the answer stays within the evidence actually found in the corpus.
- Confirm that citations point to the right source and page.
- Mark unsupported questions as successful only if the system refuses or states the limitation clearly.
