Reference-aligned text quality

What these metrics show

  • ROUGE (1 / 2 / L) F1: N-gram overlap with the reference answer—similar wording and structure score higher. Correct paraphrases can still look weaker than near-copy text.
  • BERTScore F1: Similarity in a contextual embedding space—often higher than ROUGE when the answer means the same thing but uses different words.
  • Token F1: Overlap of content words after light normalization—a straightforward lexical match between reference and model answer.
  • Not shown here: Citation presence, support vs. refusal rubric, preferred-source rank, or factual correctness. Those come from the benchmark sections above and from human review.

Scale (0–1 and percent): Each bar is a mean F1 in [0, 1] (already normalized). The chart axis uses 0–100% as the same value × 100—for example 0.914 reads as 91.4% on the scale. That is a similarity readout, not “percent of questions correct” or exam accuracy. Exact-match scores are usually near zero because references are short gold summaries, not verbatim targets.

Metric comparison (mean F1; axis as % of scale)

Each cluster compares evaluation sets on the same automatic text metrics produced by src/eval_text_metrics.py. Values are macro means over questions with both a reference answer and a model answer. Bar labels use four-digit F1; the vertical axis is F1 × 100 (percentage-style).

Hallucination and grounding (rubric proxies)

Fully automatic hallucination labels are not available here. Instead we show conservative benchmark rubric signals: whether each question’s supported vs. unsupported outcome matched the answer key, and how many citation requirements were missed on supported-looking items. High alignment and zero gaps are necessary but not sufficient for “no hallucination.”

Support rubric: aligned vs. miss (by headline suite)

Green is the share of questions where support expectation matched the key. Coral is the remainder (wrong support flag or refusal vs. key). These misses can indicate unsupported claims or incorrect refusals, either of which can look like “hallucination” or unsafe behavior to users.
